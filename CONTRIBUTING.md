# Contributing

Compatibility reports and reproducibility improvements are welcome.

Please include:

- host OS and CPU;
- QEMU, Docker, PANDA, and Windows build versions;
- accelerator and exact machine/CPU model;
- which validation gates passed;
- sanitized logs and exact error text; and
- whether the source disk was VDI-backed or already standalone qcow2.

Never submit VM images, Windows media, SSH private keys, proprietary samples,
tokens, packet captures containing private traffic, or other people's data.

Keep claims narrow. “Replay completed” and “Windows reached an interactive
desktop under PANDA” are different results and should be reported separately.
